# Идеи следующих этапов

- Подключение переносимой памяти проекта к серверным профилям агентов отдельным
  согласованным шагом, без копирования локальных секретов и Windows-путей.
- Управляемые обновления CLI с фиксацией проверенной версии и возвратом предыдущей.
- Повторная оценка канала при смене сети и предупреждение перед крупными
  приращениями уже подключённого каталога (сейчас порог проверяется при добавлении).
- Автоматический выбор свободного loopback-порта для нескольких одновременных
  live-каталогов; сейчас для них задаётся разный --remote-file-port.
